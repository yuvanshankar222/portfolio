# 🌐 Yuvan Shankar Portfolio

A modern **Cyberpunk-inspired personal portfolio website** showcasing the profile, technical skills, projects, education, and achievements of **Yuvan Shankar S. A.** Built with HTML, CSS, and JavaScript, the website delivers a futuristic UI with smooth animations and responsive design.

> **Live Demo:** https://yuvanshankar-portfolio.netlify.app/

---

## ✨ Features

- Cyberpunk-inspired UI/UX
- Fully responsive design
- Smooth scrolling animations
- Hero section with typing effect
- About section
- Skills showcase
- Education timeline
- Featured projects
- Contact section
- Modern glassmorphism effects
- Interactive hover animations
- Mobile-friendly layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- CSS Animations
- Modern UI/UX Principles
